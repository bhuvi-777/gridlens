# Security Policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private reporting: go to the **Security** tab of this repository
and choose **Report a vulnerability**. You can also email <your-email-here>.

I aim to reply within 7 days.

## Scope

GridLens reads data files (CSV, COMTRADE) and writes HTML reports. Reports of
crashes or unsafe behaviour when parsing untrusted files, or of unescaped
content in generated reports, are in scope.
